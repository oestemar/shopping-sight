# 📘 EC 管理画面 仕様書
## 1. 📌 管理画面の目的
- 管理者が EC サイトの商品・在庫・注文・ユーザー情報を管理するためのバックオフィス機能を提供する。
- 主に以下の業務を対象とする：
  - 商品一覧・登録・編集・削除
  - 注文一覧・詳細・ステータス変更
  - 在庫一覧・更新・履歴
  - カテゴリー一覧・編集・追加
  - CSV による商品一括登録
  - ユーザー一覧
  - 管理者アカウントの管理（パスワード変更など）

## 2. 🔐 認証・権限管理
### 2.1 ログイン機能
- 管理者は email / password でログインする
- パスワードは ハッシュ化（bcrypt） で保存
- ログイン後はセッション管理
- ログインしていない場合はすべての管理画面 URL へアクセス不可

### 2.2 権限（role）
- role = 0 → 一般管理者
- role = 1 → 上位管理者（商品削除・管理者追加が可能）

## 3. 🗂️ 商品管理（products）
### 3.1 商品一覧
- 機能
  - 商品の一覧表示（ID / 商品名 / 価格 / ステータス / カテゴリ）
  - キーワード検索（商品名・SKU）
  - ステータス絞り込み（販売中・売り切れ・販売停止）
  - カテゴリ絞り込み
  - 商品詳細画面への遷移
  - 商品追加画面への遷移
- 画面項目
  - 商品ID
  - 商品名
  - 価格
  - ステータス
  - カテゴリー
  - 詳細ボタン
  - 追加ボタン

### 3.2 詳細画面
- 機能
  - 商品の詳細表示（ID / 商品名 / 価格 / 在庫数 / SKU / ブランド / 説明文 / カテゴリ / ステータス）
  - 商品画像の追加
  - 商品画像の削除
- 画面項目
  - 商品ID
  - 商品名
  - 価格
  - 在庫
  - SKU
  - ブランド
  - 説明
  - カテゴリ
  - ステータス
  - 画像追加ボタン
  - 画像削除ボタン

### 3.3 商品登録（追加）画面
- 入力項目
  - 商品名（必須）
  - 在庫数（必須）
  - SKU（任意）
  - ブランド（任意）
  - 説明文（任意）
  - カテゴリ（必須）
  - ステータス（公開 / 非公開）
  - 仕様（spec_json）
    - UI は「項目名」「値」を追加できる動的フォーム
  - 商品画像（複数アップロード）

### 3.4 商品編集画面
- 機能
  - 登録画面と同じ項目を編集可能
  - 既存画像の一覧表示
  - 画像追加
  - 画像削除
  - spec_json の編集

## 10．API仕様書
### 10-1．管理者認証
| API名 | メソッド | エンドポイント | 概要 |
| --- | --- | --- | --- |
| 管理者ログイン | POST | ``/admin/login`` | email / password による認証 |
| ログアウト | GET | ``/admin/logout`` | セッション破棄 |
| ダッシュボード表示 | GET | ``/admin/dashboard`` | 管理者トップ画面 |

### 10-2．商品管理(products)
| API名 | メソッド | エンドポイント | 概要 |
| --- | --- | --- | --- |
| 商品一覧取得 | GET | ``/admin/products`` | 商品一覧を取得（検索・絞り込み対応） |
| 商品詳細取得 | GET | ``/admin/products/<int:id>`` | 商品詳細を取得 |
| 商品登録 | POST | ``/admin/products/register`` | 新規商品登録 |
| 商品編集 | POST | ``/admin/products/edit/<int:id>`` | 商品情報更新 |
| CSV商品インポート | POST | ``/admin/products/import_csv`` | CSVファイルから商品一括登録 |

### 10-3．注文管理(orders/order_items)
| API名 | メソッド | エンドポイント | 概要 |
| --- | --- | --- | --- |
| 注文一覧取得 | GET | ``/admin/orders`` | 注文一覧を取得（ステータス・日付絞り込み対応） |
| 注文詳細取得 | GET | ``/admin/orders/<int:id>`` | 注文詳細を取得（order_items含む） |
| 注文ステータス更新 | POST | ``/admin/orders/update_status/<int:id>`` | 注文ステータス変更（shipped / canceled） |

### 10-4．在庫管理(inventory)
| API名 | メソッド | エンドポイント | 概要 |
| --- | --- | --- | --- |
| 在庫一覧取得 | GET | ``/admin/inventory`` | 在庫一覧を取得 |
| 在庫更新 | POST | ``/admin/inventory/update_form1/<int:id>`` | 在庫を更新 |
| 在庫履歴（商品毎） | GET | ``/admin/inventory/history/<int:id>`` | 商品毎の在庫の履歴 |
| 在庫履歴（全体） | GET | ``/admin/inventory/`` | 商品毎の在庫の履歴 |


### 10-5．カテゴリ管理(categories)
| API名 | メソッド | エンドポイント | 概要 |
| --- | --- | --- | --- |
| カテゴリ一覧取得 | GET | ``/admin/categories`` | カテゴリ一覧を取得 |
| カテゴリ追加 | POST | ``/admin/categories/add`` | 新規カテゴリ登録 |
| カテゴリ編集 | POST | ``/admin/categories/edit/<int:id>`` | カテゴリ名・ステータス変更・順序更新 |


### 10-6．ユーザー管理(users)
| API名 | メソッド | エンドポイント | 概要 |
| --- | --- | --- | --- |
| ユーザー一覧取得 | GET | ``/admin/users`` | ユーザー一覧を取得 |
| ユーザー詳細取得 | GET | ``/admin/users/<int:id>`` | ユーザー詳細を取得（注文履歴含む） |

### 10-7．管理者管理(admins)
| API名 | メソッド | エンドポイント | 概要 |
| --- | --- | --- | --- |
| 管理者一覧取得 | GET | ``/admin/admins`` | 管理者一覧を取得（全管理者） |
| 管理者パスワード変更 | POST | ``/admin/admins/password/<int:id>`` | 管理者のパスワード変更（上位管理者のみ） |
| 管理者追加 | POST | ``/admin/admins/add`` | 管理者追加（上位管理者のみ） |
| 管理者削除 | DELETE | ``/admin/admins/delete/<int:id>`` | 管理者削除（上位管理者のみ） |



## 11．画面遷移図
```

管理者ログイン
      ↓
管理ダッシュボード
 ├─ 商品管理
 │    ├─ 商品一覧 → 商品詳細 → 商品編集 
 │    │                       └─ 画像管理（追加・削除）
 │    ├─ 商品登録 → 画像アップロード
 │    └─ CSV商品インポート
 │
 ├─ 注文管理
 │    └─ 注文一覧 → 注文詳細 → ステータス変更
 │
 ├─ 在庫管理
 │    ├─ 在庫一覧 → 在庫更新 → ステータス変更
 │    │ 　　　　　　 └─ 在庫履歴（商品毎）
 │    └─ 在庫履歴（全体）
 │
 ├─ カテゴリ管理
 │    ├─ カテゴリ一覧 → カテゴリ編集
 │    └─ カテゴリ追加
 │
 ├─ ユーザー管理
 │    └─ ユーザー一覧 → ユーザー詳細
 │
 ├─ 管理者設定
 │    ├─ パスワード変更
 │    ├─ 管理者追加
 │    └─ 管理者削除
 │
 └─ ログアウト
```
