# 📘 EC 管理画面 仕様書
## 1. 📌 管理画面の目的
- 管理者が EC サイトの商品・注文・ユーザー情報を効率的に管理するためのバックオフィス機能を提供する。
- 主に以下の業務を対象とする：
  - 商品の登録・編集・削除
  - 商品画像の管理
  - カテゴリ管理
  - 注文状況の確認・更新
  - CSV による商品一括登録
  - 管理者アカウントの管理（パスワード変更など）

## 2. 🔐 認証・権限管理
### 2.1 ログイン機能
- 管理者は email / password でログインする
- パスワードは ハッシュ化（bcrypt） で保存
- ログイン後はセッション管理
- ログインしていない場合はすべての管理画面 URL へアクセス不可

### 2.2 権限（role）
- role = 0 → 一般管理者
- role = 1 → 上位管理者（商品削除・管理者追加が可能）

## 3. 🗂️ 商品管理（products）
### 3.1 商品一覧画面
- 機能
  - 商品の一覧表示（ID / 商品名 / 価格 / 在庫 / ステータス / カテゴリ）
  - キーワード検索（商品名・SKU）
  - カテゴリ絞り込み
  - ステータス絞り込み（公開 / 非公開）
  - ページネーション
  - 商品詳細画面への遷移
  - 商品編集画面への遷移
  - 商品削除（上位管理者のみ）
- 画面項目
  - 商品ID
  - 商品名
  - 価格
  - 在庫
  - ステータス
  - カテゴリ名
  - 編集ボタン
  - 削除ボタン

### 3.2 商品登録画面
- 入力項目
  - 商品名（必須）
  - SKU（任意）
  - 価格（必須）
  - 在庫数（必須）
  - カテゴリ（必須）
  - ブランド名（任意）
  - ステータス（公開 / 非公開）
  - 説明文（任意）
  - 仕様（spec_json）
    - UI は「項目名」「値」を追加できる動的フォーム
  - 商品画像（複数アップロード）
- バリデーション
  - 商品名：255文字以内
  - 価格：整数
  - 在庫：整数
  - カテゴリ：存在する category_id
  - 画像：jpg/png のみ

### 3.3 商品編集画面
- 機能
  - 登録画面と同じ項目を編集可能
  - 既存画像の一覧表示
  - 画像の削除
  - 新規画像の追加
  - spec_json の編集

### 3.4 商品削除
- 挙動
  - 上位管理者のみ実行可能
  - product_images も同時削除
  - order_items に紐づく商品は削除不可（ステータスを非公開に変更する運用）

## 4. 🖼️ 商品画像管理（product_images）
### 4.1 画像アップロード
- 複数枚アップロード可能
- 画像は Supabase Storage / S3 に保存
- DB には image_url のみ保存
- sort_order により表示順を管理

### 4.2 画像削除
- 個別削除可能
- ストレージからも削除する

## 5. 🗂️ カテゴリ管理（categories）
### 5.1 カテゴリ一覧
- カテゴリ名
- sort_order
- 編集ボタン
- 削除ボタン

### 5.2 カテゴリ登録
- name（必須）
- sort_order（任意）

### 5.3 カテゴリ削除
- 商品が紐づいている場合は削除不可

## 6. 🧾 注文管理（orders / order_items）
### 6.1 注文一覧
- 表示項目
  - 注文ID
  - ユーザー名
  - 合計金額
  - ステータス（paid / shipped / canceled）
  - 注文日時
  - 詳細ボタン
- 絞り込み
  - ステータス
  - 日付範囲
  - ユーザー名

### 6.2 注文詳細画面
- 表示項目
  - 注文ID
  - ユーザー情報
  - 配送方法（置き配 / 対面）
  - Stripe payment_intent_id
  - 注文ステータス
  - 注文商品一覧（order_items）
    - 商品名
    - 数量
    - 注文時価格

- 操作
  - ステータス変更（shipped / canceled）

## 7. 🛒 カート管理（carts）
管理画面では通常不要だが、デバッグ用に閲覧のみ可能 とする。

- 表示項目
  - user_id
  - product_id
  - quantity
  - price_at_added

## 8. 👤 ユーザー管理（users）
### 8.1 ユーザー一覧
- ユーザーID
- 氏名
- メールアドレス
- 登録日
- 詳細ボタン

### 8.2 ユーザー詳細
- 基本情報表示
- 注文履歴一覧
- カート内容表示（デバッグ用）

## 9. 🔐 管理者管理（admins）
### 9.1 パスワード変更
- 現在のパスワード
- 新パスワード
- 新パスワード（確認）

### 9.2 管理者追加（上位管理者のみ）
- email
- password
- role

## 10. 📤 CSV インポート（商品一括登録）
### 10.1 対応フォーマット
- CSV（UTF-8）
- カラム例：
  - name
  - price
  - stock
  - category_id
  - sku
  - brand
  - status
  - description

### 10.2 バリデーション
- 必須項目の欠落チェック
- category_id の存在チェック
- price / stock の数値チェック

### 10.3 エラー処理
- エラー行を一覧表示
- 正常行のみ登録するか、全体ロールバックするか選択可能

## 11. 🧭 管理画面メニュー構成（ナビゲーション）
- ダッシュボード（任意）
- 商品管理
  - 商品一覧
  - 商品登録
  - CSV インポート
- カテゴリ管理
- 注文管理
- ユーザー管理
- 管理者設定
  - パスワード変更
  - 管理者追加（上位のみ）
- ログアウト

## 12. 🧱 非機能要件
### 12.1 セキュリティ
- CSRF 対策
- XSS 対策
- SQL インジェクション対策
- パスワードは bcrypt でハッシュ化

### 12.2 ログ
- 管理者操作ログ
- ログイン成功/失敗ログ

### 12.3 パフォーマンス
- 商品一覧はページネーション必須
- 
画像は CDN（Supabase / S3）経由で配信
