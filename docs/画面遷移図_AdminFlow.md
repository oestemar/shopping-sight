# 画面遷移図
```

管理者ログイン
      ↓
管理ダッシュボード
 ├─ 商品管理
 │    ├─ 商品一覧 → 商品詳細 → 商品編集 
 │    │                       └─ 画像管理（一覧・追加・削除）
 │    ├─ 商品登録 → 画像アップロード
 │    └─ CSV商品インポート
 │
 ├─ カテゴリ管理
 │    ├─ カテゴリ一覧 → カテゴリ編集
 │    └─ カテゴリ追加
 │
 ├─ 注文管理
 │    └─ 注文一覧 → 注文詳細 → ステータス変更
 │
 ├─ ユーザー管理
 │    └─ ユーザー一覧 → ユーザー詳細 → 注文履歴
 │
 ├─ 管理者設定
 │    ├─ パスワード変更
 │    └─ 管理者追加
 │
 └─ ログアウト
```
